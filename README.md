# iSubmit · 作业提交平台

学生通过网页把作业上传到老师的 Google Drive，彼此看不到别人的作业。一般情况下学生不需要 Google 账号，只有文件太大、需要改交分享链接时，才要先把文件存到自己的 Google Drive。

## 主要功能

- **学生提交页**：选择班级、从名单中选自己的名字、选择作业，拖拽上传一个或多个文件；文件太大时可以改交自己 Google Drive 的分享链接。提交后显示回执。
- **管理页**：设置班级与学生名单、作业标题与截止时间、提交口令、文件类型与大小限制，修改管理密码。
- **提交情况**：按作业查看每个班谁已交、谁未交、谁迟交，一键复制未交名单，直接打开学生提交的链接。
- **多语言**：学生页和管理页都可切换 华文 / English / Bahasa Melayu / தமிழ்。
- **自动整理**：文件按「班级 / 作业」存进 Drive，命名为「姓名_原文件名」；重复提交保留旧文件，迟交的文件名会加上「【迟交】」，每次提交都记录在一份 Google 表格中。

## 原理

网页本身只是静态页面，可以放在 GitHub Pages 或任何网页服务器上。上传的文件交给一个以老师身份运行的 Google Apps Script，由它写进老师的 Drive。学生只能通过这个脚本「上传」，没有任何查看文件的途径，所以看不到别人的作业。
