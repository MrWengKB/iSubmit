# iSubmit · 作业提交平台

学生通过网页上传作业，文件直接存进**老师自己的 Google Drive**。
学生不需要 Google 账号，也**看不到任何其他同学的作业**。

- `index.html`：学生提交页，学生依次选择班级、自己的名字、作业，然后上传文件；文件太大时也可以提交自己 Google Drive 的分享链接
- `admin.html`：老师管理页，设置班级、学生名单、作业和截止时间，查看谁交了、谁没交

## 工作原理

```
学生 index.html ─┐
                 ├─▶ Google Apps Script（以老师身份运行）─▶ 老师的 Google Drive
老师 admin.html ─┘                                          iSubmit 作业提交/
                                                              ├─ 三年二班/第1次作业/李四_报告.pdf
                                                              ├─ iSubmit 提交登记（表格）
                                                              └─ iSubmit 设置.json
```

- 脚本以「我」（老师）的身份运行，Drive 文件夹不共享给任何人，每个文件都设为私有。
- 学生页面只能上传，没有任何查看或下载文件的接口，所以学生看不到别人的作业。
- 管理页需要管理密码才能进入，密码只以加盐哈希的形式保存。

## 一次性部署（约 10 分钟，以后不用再改代码）

### 1. 部署后端
1. 打开 <https://script.google.com> → **新项目**，把 `apps-script/Code.gs` 全部粘贴进去，保存。**不需要修改任何内容。**
2. 齿轮「项目设置」→ 时区改成 `(GMT+08:00) Singapore`（或你所在地区）。
3. 函数下拉框选 `setup` → **运行**，按提示授权（出现「Google 尚未验证此应用」时点 **高级 → 转至…**，这是你自己的脚本）。
4. **部署 → 新建部署 → 网页应用**：
   - 执行身份：**我**
   - 谁可以访问：**任何人**
5. 复制得到的网址（以 `/exec` 结尾）。

### 2. 填写网址
打开 `config.js`，把网址粘贴进去：
```js
window.ISUBMIT_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

### 3. 发布网页（GitHub Pages）
1. 把整个文件夹推送到 GitHub 仓库 `iSubmit`。
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`，保存。
3. 一两分钟后：
   - 学生提交页：`https://<你的用户名>.github.io/iSubmit/`
   - 管理页：`https://<你的用户名>.github.io/iSubmit/admin.html`

### 4. 立刻设置管理密码
马上打开管理页。第一次进入时会要求你设置管理密码。**请在部署后立即完成这一步**，否则别人可能先你一步设置密码。

## 日常使用（全部在管理页完成）

| 标签页 | 做什么 |
| --- | --- |
| 班级与名单 | 添加班级，每行粘贴一个学生名字（可以直接从 Excel 复制一列） |
| 作业 | 添加作业标题、截止时间，勾选需要提交的班级，开放或关闭提交 |
| 设置 | 提交口令、文件大小上限、允许的文件类型、截止后是否还能交、修改管理密码 |
| 提交情况 | 按作业查看每个班「已交 / 未交」，可以一键复制未交名单 |

改完记得点底部的 **保存设置**。

## 注意事项

- **身份**：学生从名单中选择自己的名字，系统无法验证选的是不是本人。建议设置提交口令，并留意「已交 N 份」异常的情况。
- **文件大小**：单个文件最大 35 MB（受 Apps Script 请求大小限制），默认 20 MB。更大的文件（例如视频）请学生存到自己的 Google Drive 再提交分享链接。链接会记在登记表里，同时在作业文件夹中存一个「姓名_链接_时间.txt」，在管理页「提交情况」里可以直接点开。
- **重复提交**：不会覆盖旧文件，新文件名会带时间戳；截止后提交的文件，文件名前会加「【迟交】」。
- **重名学生**：同一个班里名字不能重复，请加以区分（例如 张伟A / 张伟B）。
- **忘记管理密码**：在 Apps Script 编辑器 →「项目设置 → 脚本属性」中删除 `ADMIN_HASH`，然后重新打开管理页设置新密码。
- **更新代码**：如果以后替换了 `Code.gs`，需要「部署 → 管理部署 → 编辑 → 版本：新版本 → 部署」，网址保持不变。
