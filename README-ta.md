# iSubmit · வீட்டுப்பாடம் சமர்ப்பிப்பு

மாணவர்கள் ஓர் இணையப் பக்கம் மூலம் தங்கள் வீட்டுப்பாடங்களை நேரடியாக ஆசிரியரின் Google Drive-இல் பதிவேற்றுகிறார்கள்; ஒருவர் மற்றவரின் வீட்டுப்பாடத்தைப் பார்க்க முடியாது. பொதுவாக மாணவர்களுக்கு Google கணக்கு தேவையில்லை; கோப்பு மிகப் பெரியதாக இருந்து அதற்குப் பதிலாகப் பகிர்வு இணைப்பைச் சமர்ப்பிக்கும்போது மட்டுமே, முதலில் அதைத் தங்கள் சொந்த Google Drive-இல் சேமிக்க வேண்டும்.

## முக்கிய அம்சங்கள்

- **மாணவர் சமர்ப்பிப்புப் பக்கம்**: வகுப்பைத் தேர்ந்தெடுத்து, பட்டியலிலிருந்து தங்கள் பெயரைத் தேர்வு செய்து, வீட்டுப்பாடத்தைத் தேர்ந்தெடுத்த பின், ஒன்று அல்லது பல கோப்புகளை இழுத்து விடலாம். கோப்பு மிகப் பெரியதாக இருந்தால், சொந்த Google Drive-இலிருந்து பகிர்வு இணைப்பைச் சமர்ப்பிக்கலாம். சமர்ப்பித்த பின் ரசீது காட்டப்படும்.
- **நிர்வாகப் பக்கம்**: வகுப்புகள், மாணவர் பட்டியல்கள், வீட்டுப்பாடத் தலைப்புகள், கடைசி நாட்கள், சமர்ப்பிப்புக் குறியீடு, அனுமதிக்கப்பட்ட கோப்பு வகைகள், அளவு வரம்பு ஆகியவற்றை அமைக்கலாம்; நிர்வாகக் கடவுச்சொல்லை மாற்றலாம்.
- **சமர்ப்பிப்பு நிலவரம்**: ஒவ்வொரு வீட்டுப்பாடத்துக்கும், ஒவ்வொரு வகுப்பிலும் யார் சமர்ப்பித்தனர், யார் சமர்ப்பிக்கவில்லை, யார் தாமதமாகச் சமர்ப்பித்தனர் என்று பார்க்கலாம்; சமர்ப்பிக்காதோர் பட்டியலை ஒரே சொடுக்கில் நகலெடுக்கலாம்; மாணவர்கள் சமர்ப்பித்த இணைப்புகளைத் திறக்கலாம்.
- **பல மொழிகள்**: இரண்டு பக்கங்களிலும் 华文 / English / Bahasa Melayu / தமிழ் ஆகியவற்றுக்கு இடையே மாற்றலாம்.
- **தானியங்கி ஒழுங்கமைப்பு**: கோப்புகள் Drive-இல் வகுப்பு / வீட்டுப்பாடம் வாரியாகச் சேமிக்கப்பட்டு, "பெயர்_மூலக்-கோப்புப்-பெயர்" என்று பெயரிடப்படுகின்றன. மீண்டும் சமர்ப்பித்தால் முந்தைய கோப்புகள் வைத்திருக்கப்படும்; தாமதமான கோப்புகளின் பெயருக்கு முன் "[LATE]" சேர்க்கப்படும்; ஒவ்வொரு சமர்ப்பிப்பும் ஒரு Google Sheet-இல் பதிவு செய்யப்படும்.

## இது எப்படி வேலை செய்கிறது

இணையப் பக்கங்கள் வெறும் நிலையான (static) பக்கங்கள்; அவற்றை GitHub Pages அல்லது எந்த இணையச் சேவையகத்திலும் வைக்கலாம். பதிவேற்றப்படும் கோப்புகள் ஆசிரியரின் பெயரில் இயங்கும் ஒரு Google Apps Script-இடம் ஒப்படைக்கப்பட்டு, அது அவற்றை ஆசிரியரின் Drive-இல் சேமிக்கிறது. மாணவர்கள் இந்த ஸ்கிரிப்ட் மூலம் "பதிவேற்ற" மட்டுமே முடியும்; எந்தக் கோப்பையும் பார்க்க வழியில்லை. எனவே மற்ற மாணவர்களின் வீட்டுப்பாடங்களைப் பார்க்க முடியாது.
